# System Design

This repository contains notes, designs, and architectural plans for various system design problems. The concepts are divided into High-Level Design (HLD) and Low-Level Design (LLD) to cover both macro-architecture and object-oriented paradigms.

## 📁 Repository Structure

### [HLD](./HLD/) (High-Level Design)
Focuses on system scalability, architecture, data flow, distributed systems, and real-world system modeling.
- **Social Media:** Feed generation, graph storage, caching over social graphs.
- **Uber / Ride Sharing:** Location tracking, dispatch services, geospatial indexing.
- **Notification System:** Scalable and reliable push/SMS/email delivery pipelines.

### [LLD](./LLD/) (Low-Level Design)
Focuses on object-oriented paradigms, class modeling, design patterns, concurrent programming, and extensible system abstractions. *(Populate this folder with class diagrams, interface definitions, and machine coding solutions)*

## 🚀 Purpose
These notes are tailored for tackling L4/L5 engineering interview scenarios at top-tier tech companies (e.g., Google, Meta) and serve as a knowledge base for robust software engineering practices.
